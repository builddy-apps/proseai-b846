# ProseAI

AI-powered writing studio with chat-based interface, multiple writing modes, document management, and writing statistics tracking

Built with [Builddy](https://builddy.dev) — AI-powered app builder using GLM 5.1.

## Features

- chat_based_ai_interface_with_streaming
- 5_writing_modes_with_contextual_ai_prompts
- document_management_with_search_and_filter
- real_time_word_count_and_readability_metrics
- tone_and_style_adjustment_sliders
- template_library_for_quick_starts
- markdown_rendering_with_live_preview
- writing_statistics_with_daily_goals_and_streaks
- export_options_copy_markdown_plain_text
- session_context_memory_for_coherent_conversations
- dark_mode_with_warm_color_palette
- responsive_design_for_mobile_and_desktop

## Quick Start

### Local Development

```bash
npm install
npm run dev
```

Open http://localhost:3000

### Docker

```bash
docker compose up
```

### Deploy to Railway/Render

1. Push this directory to a GitHub repo
2. Connect to Railway or Render
3. It auto-detects the Dockerfile
4. Done!

## Tech Stack

- **Frontend**: HTML/CSS/JS + Tailwind CSS
- **Backend**: Express.js
- **Database**: SQLite
- **Deployment**: Docker
